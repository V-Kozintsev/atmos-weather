# Atmos — погода в деталях

[Android в RuStore](https://www.rustore.ru/catalog/app/ru.puskweb.atmos) · [Открыть веб-версию →](https://v-kozintsev.github.io/atmos-weather/)

[Скачать для Windows](https://github.com/V-Kozintsev/atmos-weather/releases/latest/download/Atmos-Setup-x64.exe) · [Без установки](https://github.com/V-Kozintsev/atmos-weather/releases/latest/download/Atmos-Portable-x64.exe)

Погодная панель, с которой можно строить планы: сейчас, следующие 24 часа и неделя впереди.

- Интерактивный SVG-график температуры, осадков и ветра; выбор дня и часа.
- Поиск городов с клавиатурной навигацией, геолокация по запросу, избранное и ссылки на прогноз.
- УФ-индекс, восход и закат. Подбор дневного часа для прогулки, бега и велосипеда по прозрачным правилам.
- Подбор одежды для ближайшего часа и до конца дня: женский или мужской образ, полный комплект по категориям, повседневный/офисный/активный стиль и настройка чувствительности к холоду.
- Поиск похожих вещей на Ozon и Wildberries по выбранному элементу образа. Ссылки обычные, без начисления комиссии.
- Прогноз MET Norway и локальный поиск городов GeoNames; отмена устаревших запросов, кэширование до обновления источника и сохранённый прогноз при сбое сети.
- Адаптивный интерфейс, локальные шрифты, доступные состояния и поддержка reduced motion.
- Устанавливаемое PWA: отдельное окно, иконка приложения, офлайн-интерфейс и проверка обновлений при возвращении и раз в час.
- Windows-приложение на Electron: локальный интерфейс, сворачивание в область уведомлений, мини-погода поверх окон, текущая температура в подсказке значка и обновление установленной версии через GitHub Releases.
- Мобильная версия 3.0 на React Native / Expo в `mobile/`: компактный интерфейс, Android-виджет погоды и одежды, отдельные мужские и женские образы, увеличение фото жестами, настраиваемое напоминание об оценке и атмосферные фоны городов. Геолокация — по нажатию через системное разрешение. Android-версия 2.2.1 опубликована в RuStore; обновление 3.0 отправлено на модерацию. Публикации iOS пока нет.

**React · React Native · Expo · TypeScript · Vite · Electron · PWA / Workbox · SVG · REST API · Vitest**

## Как установить

**Windows 10/11 (64 бит):** скачайте установщик или portable-версию по ссылкам выше. Закрытие окна сворачивает Atmos в область уведомлений; полное завершение — через меню значка. «Мини-погода» показывает компактную панель поверх других окон. Интерфейс включён в приложение, новый хостинг не нужен. Свежий прогноз загружается из MET Norway. Установщик проверяет новые версии через GitHub Releases и предлагает перезапуск после загрузки; portable-файл обновляется заменой вручную. Сборка пока без цифровой подписи.

[Мини-панель в браузере](https://v-kozintsev.github.io/atmos-weather/?view=mini) доступна без установки. Этот режим не закрепляет окно поверх других приложений.

Откройте приложение и нажмите «Установить». В Chrome и Edge также доступна установка из меню браузера. На iPhone/iPad: Safari → «Поделиться» → «На экран Домой».

После первого успешного запуска интерфейс доступен без сети. Последний прогноз сохраняется до суток и отмечается как сохранённый; для новых данных нужен интернет. Service worker сохраняет ресурсы приложения и локальный справочник городов, без запросов с координатами.

## Запуск

Node.js 22.18+ или 24+. Установка: `npm ci`. Разработка: `npm run dev`. Проверки: `npm test` и `npm run typecheck`. Сборка: `npm run build`; просмотр сборки: `npm run preview`.

Windows-приложение: `npm run desktop`; установщик и portable EXE: `npm run desktop:build`. В оболочке отключён доступ веб-интерфейса к Node.js; локальные файлы загружаются через ограниченный протокол, внешние HTTPS-ссылки открываются в браузере. Город в desktop-версии выбирается через поиск и избранное.

Мобильная версия: после `npm ci` в корне выполните `npm --prefix mobile ci`. `npm run native:dev` запускает локальный просмотр на порту 9002; `npm run native:android` собирает отдельное тестовое приложение `ru.puskweb.atmos.dev` для Android-эмулятора или телефона. Нужны Android Studio / Android SDK и совместимый JDK. Проверка типов: `npm run native:typecheck`. Для iOS нужен Mac с Xcode; запуск — `npm --prefix mobile run ios`.

Релиз Android использует прежний пакет `ru.puskweb.atmos` и существующий ключ подписи: значения `ATMOS_KEYSTORE`, `ATMOS_STORE_PASSWORD`, `ATMOS_KEY_ALIAS`, `ATMOS_KEY_PASSWORD` передаются через окружение. Ключи и пароли не хранятся в репозитории. Нативные папки создаются через Expo prebuild. Старые проекты Capacitor сохраняются для совместимости: `npm run mobile:sync` обновляет их веб-ресурсы, но не собирает новую версию React Native.

Диагностика оболочки: запуск `Atmos.exe --diagnostics`. Префикс `[Atmos Desktop]`; пользовательские данные не выводятся. Аргумент `--background` запускает приложение сразу в области уведомлений. Windows-сборки публикуются из тегов `v*` через GitHub Actions.

API-ключи и отдельный сервер не нужны. Погодные данные предоставляет [MET Norway](https://api.met.no/) по [открытой лицензии](https://api.met.no/doc/License), допускающей коммерческое использование с указанием источника. Поиск на устройстве основан на [данных GeoNames](https://www.geonames.org/export/) (CC BY); выборка содержит 20 тысяч крупных городов и города России из набора cities15000. Время отображается в часовом поясе выбранного города. Геолокация округляется до 0,01° и передаётся MET Norway только по нажатию «Где я». Избранное и последний прогноз хранятся в браузере; сохранённые данные явно отмечены и используются не дольше суток. Осадки отображаются в миллиметрах, а не как вероятность.

Стиль и чувствительность к холоду сохраняются только на устройстве. В приложении пока нет рекламы, партнёрских ссылок и каталога товаров; для комиссии необходимы одобренная партнёрская площадка и выданные ею ссылки. Кнопки магазинов открывают обычный поиск.

Диагностика API включается командой `localStorage.setItem('atmos-debug', 'true')` в консоли браузера. Префикс `[Atmos API]`; координаты и текст поиска не выводятся. Отключение: `localStorage.removeItem('atmos-debug')`.
